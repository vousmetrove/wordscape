# Wordscape Listening

一个专注于雅思听力词汇听写的静态网站。网站一次只练习一个词，不再包含原来的背单词、复习计划、中文翻译或错题本模块。

## 学习方式

1. 选择要练习的章节。
2. 在左侧可搜索的单词列表中点击任意单词，将它保存为新的练习起点。
3. 选择每个新词自动播放以及再次点击发音时的播放次数和速度。
4. 根据音标和音频拼写单词；需要提示时，点击按钮查看中文释义。
5. 输入错误时，错误或缺失的字符会标红，并自动出现一个新输入框。
6. 同一个词累计输入正确 3 次后自动进入下一个词；答错不会清除已经获得的正确次数。

页面会记住当前章节、播放设置和各章节的学习位置。学习记录只保存在当前浏览器的 `localStorage` 中。

## 词库

- 5,230 个去重后的听力词条
- 34 个原始章节分类
- 每个词条包含音标、中文释义和章节信息
- 数据来自用户提供的《雅思听力语料库智能自测表.xlsx》

原始表格共整理出 5,918 条可用记录，合并重复词条后得到 5,230 个词。原始工作簿不包含在仓库内。

## 发音

网站会预取 Free Dictionary API 提供的真人词典录音，但只接受地址或元数据明确标记为 UK、GB 或 British 的录音；美式、澳式、加拿大式以及地区不明的录音一律不会播放。词典没有明确的英式录音或网络暂时不可用时，网站只从设备的 `en-GB` 语音中选择 Natural、Neural、Premium 或 Enhanced 等高质量声音。若设备没有列出 `en-GB` 声音，则不主动选择其他地区声音，而是让浏览器按 `en-GB` 语言要求发音。

每次进入新单词时会按照当前设置自动播放；播放结束后，仍可点击按钮再次播放。可以选择播放 1、2、3、5 或 10 次，以及 1、1.2、1.4 或 1.6 倍速。词典录音地址会在练习当前词时预取，因此后续播放和下一词播放不会等待查询。

建议使用最新版 Chrome、Edge 或 Safari，并确保设备音量开启。如果系统没有英式英语语音，网站仍会向浏览器明确请求 `en-GB`，不会主动选择其他地区的英语语音。

## 本地打开

这是一个纯静态网站。可以直接打开 `index.html`，也可以在项目目录中启动静态文件服务：

```bash
python -m http.server 4173
```

随后访问 `http://localhost:4173`。

## 隐私

章节位置和练习设置仅保存在浏览器本地，不会上传个人学习记录。为了查找真人录音，网站会向 Free Dictionary API 发送当前词和下一个词的英文拼写，不会发送学习记录或其他个人信息。
